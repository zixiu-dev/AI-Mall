## MODIFIED Requirements

### Requirement: CACHE-002 穿透防护

系统 SHALL 在参数校验通过且本地缓存未命中后、读取共享详情缓存及申请重建锁之前检查存在性，能够明确否定商品 ID 时避免锁竞争和数据库回源；对可能存在但实际查不到的详情保存短期空结果，过滤器未知时不得错误拒绝合法商品。

#### Scenario: 明确不存在

- **GIVEN** 存在性过滤已就绪并判断 ID 不存在
- **WHEN** 该详情未命中本地缓存
- **THEN** 直接返回无商品，不读取共享详情缓存、不申请缓存重建锁、不读取数据库。

#### Scenario: 过滤器误判

- **GIVEN** 过滤判断可能存在但数据库没有该商品
- **WHEN** 读取详情
- **THEN** 保存短期空结果，重复查询在有效期内不反复回源。

#### Scenario: 过滤不可用

- **GIVEN** 存在性过滤未就绪或故障
- **WHEN** 查询合法商品
- **THEN** 继续受保护的读取路径，不直接当成不存在。

#### Scenario: 本地命中不额外查询存在性

- **GIVEN** 公共详情在有效的本地缓存中命中
- **WHEN** 查询同一商品
- **THEN** 直接返回，不为存在性过滤额外访问共享 Redis。
