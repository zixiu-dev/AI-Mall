# 实际验证

- 本机 Chrome 连接独立的 Spring Boot 商城与管理端，数据库为 H2，主备模型使用本机 OpenAI 兼容流式替身。提交三个轮次，验证同一会话的两轮可以单独打开，另一个会话单独分组。
- 模拟主模型首次返回 HTTP 503，备用模型发起两个商品详情调用，第二步再次请求主模型。验证同一步保留主备两个调用，两个工具都只出现在来源模型下，排队在轮次顶层，模型用量、状态和耗时可见。
- 浏览器拦截单次响应模拟来源模型尚未入库，验证工具仍可见、刷新后关联恢复。也验证生成中的空明细、键盘折叠、390 像素宽无页面横向溢出、错误用户查询以及商城端口隔离。
- `mvn -o -q -Dtest=AgentResumeHttpIntegrationTest test`，5 项通过，0 失败。JavaScript 语法检查及 `git diff --check` 通过。OpenSpec 归档前严格校验 20 项通过。
- 归档后 OpenSpec 严格校验 19 项通过。本机商城更新后健康检查为 `UP`，管理端返回新版执行树，并能读取已有的模型与工具关联记录。
