# 真实目录设计

商品身份采用新编号，原虚构商品仅下架，不把旧 SKU 改名为另一款真实商品，避免历史库存、预占和订单身份失真。新增 V17，MySQL/H2 各自兼容，保持历史迁移校验和。

商品来源清单作为可复核的数据工件，记录来源、SKU 价格与规格、图片原始 URL、本地文件、核对日期。生成 SQL 与前端图片索引，数据库属性也保存来源，使 Agent 同样能读取。实际交易只认数据库，前端清单不决定价格。

图片来自品牌公开商品资料并本地保存，页面运行不依赖第三方图片请求。保留品牌权属说明，未找到对应图片不伪造替代。官网价与历史发布价明确区分，不抓取会员券后价、补贴价或员工价。

旧目录价格边界和历史订单的回归用例使用显式测试夹具；新增隔离数据库用例覆盖完整迁移、来源、旧快照保护及新商品购买。测试夹具只在 test 资源，不进入应用 JAR。
