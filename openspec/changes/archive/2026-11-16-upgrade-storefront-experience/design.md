# 前台设计

## Context

保留无构建依赖的原生模块，复用现有服务；从弹窗布局改为 hash 路由页面，浏览器返回、刷新商品详情和订单入口可用。

## Decisions

1. 首页采用搜索导航、品类入口、主题主视觉、精选商品、优惠券和商品目录；参考小米商城的信息层次与宜家场景化陈列，使用本项目品牌与商品。
2. navigation.js 管理页面可见性与历史；app.js 管接口及交易；storefront.js 管陈列、收藏、SKU 详情。常规业务页面不使用模态弹窗，确认和订单详情保留原生 dialog。
3. 页面金额来自接口；结算重新试算并生成 trace，提交及未知结果恢复沿用原 trace。处理中不是建单成功，建单成功是待付款。
4. 倒计时只提示服务端截止时间，到期刷新状态，不自行修改订单。取消需确认；模拟支付显式标注。
5. 手机使用单列详情、可折叠筛选和底部导航；键盘焦点、可访问名称及减少动效偏好统一处理。

## Validation

隔离 H2 演示进程验证真实 REST/SSE 页面集成，桌面和手机截图检查。不得将此验证声称为真实 Redis、MQ 或付款渠道验证。
