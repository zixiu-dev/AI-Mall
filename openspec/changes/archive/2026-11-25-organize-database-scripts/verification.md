# 实际验证

- `python3 -B scripts/export-database-schema.py` 从隔离 MySQL 临时库重放 V1～V22，导出 8 份脚本、30 张表，再开启外键检查按编号导入第二个空库。比对字段、索引、约束和注释通过。与原 V21 DDL 对照，去除注释和等价的显式字符集写法后 30 张表定义一致。
- 9 项迁移相关测试通过。MySQL 8.0 临时库校验全部 30 张业务表、269 个字段的注释覆盖，并验证下单、并发幂等和 Agent 持久化。H2 验证历史库升级、既有订单及库存数据和注释覆盖。
- PostgreSQL 17.11 临时库通过真实 pgvector 适配器执行独立 Flyway V1～V2，使用可控向量替身。将 PG 快照导入另一个空库，排除 Flyway 历史后比对 knowledge schema 的索引、约束和注释一致。
- 独立配置下 `mvn -o -q test` 共 268 项通过、24 项按环境条件跳过，0 失败。历史迁移文件对照无差异，`git diff --check` 通过。
