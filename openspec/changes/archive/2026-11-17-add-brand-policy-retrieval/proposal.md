# 品牌政策文档与意图检索

## Why

现有 knowledge_document 只有扁平关键词与正文，品牌政策与本商城规则无法区分，商品替换为真实品牌后容易串用退货天数、保修与配送条件。

## What Changes

- 引入 Apple、小米/米家/Redmi、Nike、IKEA、MUJI 官方政策的可读摘要文档及来源、渠道、地区、版本和核对日期。
- 按品牌别名、产品家族与文档类别识别检索意图；模型可传结构化品牌/类别，服务端严格过滤并处理冲突、缺失与无结果。
- 品牌政策仅作对应官方渠道参考；本平台售后执行仍按共享业务服务，不套用品牌规则改变交易。
- 助手回答引用检索来源，页面支持安全的 HTTPS 引用链接。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `customer-service`：修改 SUPPORT-003，新增 SUPPORT-004 品牌分类意图和 SUPPORT-005 引用与渠道边界。

## Impact

V18 双数据库迁移扩展知识元数据并导入政策文档；改知识 Service/DAO、只读检索工具、系统提示和演示回复；新增只读查询 API 供调试与页面复用。无向量库或额外模型调用，无交易状态变化。

## Scope Boundary

保持 SQL 关键词检索，不称为向量 RAG。官方资料为人工核对摘要，非实时同步；未收录的品牌/类别不冒用其他规则。本次不根据政策自动裁决售后或接入真实退款。
