## 消息与事务

`chat_message` 的助手占位行保存生成状态、原问题编号和唯一请求键。问题与占位共同提交，最终正文、状态、确认卡关联共同更新。历史记录的新增属性为空，继续作为普通消息展示。模型历史和较早摘要排除未完成或失败的助手占位。

## 后台执行与订阅

后台轮次使用共享的 Agent 执行池与会话门禁。每条回答在本进程维护草稿、版本及有限个订阅者。登记订阅和排入快照共用同一把锁，之后的增量按版本入队。独立有界线程池负责网络写入。慢连接队列积压时，用较新的完整草稿替代待发送的旧事件。

浏览器用同一助手消息编号重连，只读取当前草稿与新版本。没有活跃流但已生成结束时，SSE 从数据库返回终态。此功能按单实例部署设计，进程重启时把遗留的生成中占位标记为中断。兼容入口 `POST /api/agent/chat/stream` 保留原连接断开取消行为。
