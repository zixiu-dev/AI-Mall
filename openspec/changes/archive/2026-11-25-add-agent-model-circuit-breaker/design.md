# 设计

在 SpringAiResponder 和 SpringAiStreamReader 之间增加进程内 ModelGateway。主模型保持现有连接配置，备用百炼默认关闭，启用后使用可配置的 OpenAI 兼容 base URL 与 qwen-plus。候选独立持有熔断器。这次只作用于商城 Agent 的聊天推理。

每次推理按主、备顺序各最多调用一次。单候选超时沿用现有 60 秒限制，同时受 AgentExecution 整轮截止时间约束。网络故障、上游流不完整、HTTP 408/429/5xx、仍有总预算的单次推理超时计入熔断。输入、鉴权等非瞬时失败直接结束。取消或整轮超时不计入熔断。SDK 重试保留为零。

同一熔断器的短状态操作用同步方法串行化，调用期间不持锁。使用单调时间计算冷却。熔断、恢复、释放半开许可都会推进状态版本，过期许可的回调不更新现态。

切换前发送 reset 清理已显示的草稿。流结束且有有效文本或工具请求才记成功，兼容协议流还必须收到结束原因。下游通过原工具循环校验和执行工具。无可用模型时，后台轮次在关闭执行上下文后核对确认卡，存在时保留原操作并以待确认回复结束。
